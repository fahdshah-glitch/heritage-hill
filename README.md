# Heritage Hill

A 3D world you can explore in your browser or on Android: the Heritage Hotel, a 1970s town, a theme park with roller coasters, go-karts and live shows, the Splash Bay water park, country estates and farms, traffic, day/night and aurora skies.

- **Play in the browser:** open `index.html`.
- **Android app:** download `HeritageHill.apk` from the [latest release](../../releases/latest) and install it on your phone (allow "install unknown apps" when asked). The app runs fully offline.

The APK is built automatically by GitHub Actions on every push (`.github/workflows/build-apk.yml`).
